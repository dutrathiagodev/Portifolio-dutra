## Sobre

Portfólio pessoal desenvolvido com **HTML, CSS e JavaScript puro** (sem
frameworks e sem build), em tema escuro. Cada seção é uma página estática
própria, com seu próprio CSS. O JS de navegação é compartilhado entre todas
as páginas; só a página de contato tem um script próprio, para o formulário.

## Estrutura

```
index.html              pagina inicial (hero)
sobre/sobre.html         sobre mim
experiencia/experiencia.html   trajetoria profissional
projetos/projetos.html   projetos desenvolvidos
skills/skills.html       tecnologias e competencias
contato/contato.html     formulario de contato
contato/contato.js       logica do formulario de contato
js/nav.js                destaque do item ativo no menu (compartilhado)
img/                     imagens e favicon
```

## Funcionalidades

- Navegação entre páginas (Sobre, Experiência, Projetos, Skills, Contato)
  com destaque automático do item ativo no menu
- Layout responsivo (desktop, tablet e celular)
- Formulário de contato no estilo "mad-lib", que monta um e-mail (`mailto:`)
  já preenchido com os dados digitados — sem backend/servidor

## Feito com HTML, CSS e JavaScript

Apesar de eu trabalhar principalmente com Flutter, React e Node.js, este
portfólio foi construído do zero em **HTML, CSS e JavaScript puro, sem
frameworks e sem build** — cada seção é uma página estática independente.

- **HTML5** — estrutura semântica
- **CSS3** — variáveis de cor, Grid/Flexbox, `clamp()` e media queries para
  responsividade
- **JavaScript** — interatividade (menu ativo, envio do formulário de
  contato)

## Como rodar localmente

```bash
git clone https://github.com/dutrathiagodev/Portifolio-dutra.git
cd Portifolio-dutra
```

Depois é só abrir o arquivo `index.html` no navegador, ou usar a extensão
**Live Server** do VS Code.
